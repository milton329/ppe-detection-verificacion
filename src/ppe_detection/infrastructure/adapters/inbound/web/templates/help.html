¿Qué hace este sistema?

Sube una foto de una persona en un entorno industrial y el modelo melihuzunoglu/ppe-detection (YOLOv11) detecta si porta casco y chaleco de seguridad, dibujando una caja sobre cada elemento que reconoce.

Clases detectadas

  • Casco — casco de seguridad puesto.
  • Sin casco — cabeza detectada sin casco.
  • Chaleco — chaleco reflectante de seguridad.
  • Persona — usada como referencia para ubicar el resto.

¿Qué es el umbral de confianza?

El modelo asigna a cada detección un porcentaje de certeza. El umbral filtra las detecciones más dudosas: un umbral bajo (ej. 0.10) muestra más cajas pero con más riesgo de falsos positivos; un umbral alto (ej. 0.50) muestra solo las detecciones muy seguras, pero puede ocultar elementos reales que el modelo detectó con poca confianza. Un buen punto de partida es 0.25.

Consejos para una buena foto

  • Una sola persona por imagen, de cerca (no en grupo ni muy lejos).
  • Fondo real de obra o industria, no fotos de estudio recortadas sobre fondo de color sólido.
  • Buena iluminación y casco/chaleco bien visibles, sin obstrucciones.

Limitación conocida

En pruebas internas, el modelo detecta bien la clase Casco y Persona, pero le cuesta reconocer Chaleco en fotos de banco de imágenes tipo estudio (persona recortada sobre fondo de color liso): la confianza cae a menos del 1%, incluso cuando el chaleco es claramente visible para una persona. Esto ocurre porque el modelo fue entrenado con fotos reales de obra/construcción, muy distintas visualmente a ese tipo de foto. Para resultados confiables, usa fotos de escenarios industriales reales.
